# 常见问题（FAQ）

## 基础使用

### Q: TCK 需要付费吗？

系统本身不收费。你只需要自备大模型 API Key，Token 费用由模型服务商直接收取。TCK 不代收、不转售、不加价。

### Q: 需要注册账号吗？

不需要会员、不需要订阅、不需要积分，打开就能用。

### Q: 支持哪些大模型？

所有支持 OpenAI 兼容接口的模型都可以使用，包括但不限于 OpenAI GPT 系列、Anthropic Claude、通义千问、DeepSeek 等。

### Q: 我的 API Key 安全吗？

API Key 仅存储在你本地，不会上传到任何服务器。记忆层的所有数据也存在本地数据库中。

## 上下文管理

### Q: 六种策略必须选一个吗？

是的，同一时间只能使用一种策略。但你可以随时切换，切换后立即生效于下一次请求。

### Q: 切换策略后之前的消息会丢失吗？

不会。所有消息始终保存在记忆层。切换策略只影响投喂层（即发给模型的内容），不影响存储。

### Q: 能不能恢复之前的上下文状态？

可以。记忆层完整保存所有历史，你可以搜索、回溯、恢复到任何一个历史节点。

### Q: 全量上下文策略会消耗很多 Token 吗？

是的。`full` 策略不裁剪，所有消息全部发送。建议仅在对话初期或重大决策点使用。日常对话推荐 `headTail` 或 `slidingWindow`。

## 与其他工具对比

### Q: 和直接用 ChatGPT 有什么区别？

核心区别是上下文控制能力。原生对话是"全量塞入，无法裁剪"，TCK 是"精准裁剪，按需投喂"。此外 TCK 支持多模型切换、历史回溯、数据本地存储。

### Q: TCK 是开源的吗？

TCK 为闭源项目，但系统本身不收费。本 GitHub 仓库仅用于项目介绍和文档分享。

### Q: 可以用于团队协作吗？

当前版本主要面向个人开发者使用。团队协作功能在规划中。

## 技术问题

### Q: 技术原理有论文支撑吗？

有。上下文衰减是已被多篇学术论文验证的现象，详见 README 中的论文引用列表。

### Q: 本地数据库是什么格式？

记忆层使用本地数据库存储，具体技术实现细节暂不公开，但数据可导出。

### Q: 支持自己部署吗？

当前版本为在线服务模式，访问 https://ctk.cyber001.cn/official/ 即可使用。
