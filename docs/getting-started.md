# 快速上手

## 第一步：访问系统

打开浏览器，访问：**https://ctk.cyber001.cn/official/**

无需注册账号，无需会员，打开即可使用。

## 第二步：配置 API Key

进入系统后，在设置页面配置你的大模型 API Key。

TCK 支持所有 OpenAI 兼容接口，包括但不限于：

- OpenAI GPT 系列
- Anthropic Claude 系列
- 通义千问
- DeepSeek
- 其他 OpenAI 兼容服务

> 注意：API Key 仅存储在你本地，不会上传到任何服务器。

## 第三步：创建任务

点击"新建任务"，输入任务名称和初始上下文。

初始上下文建议包含：
- 任务目标
- 技术约束
- 背景信息

## 第四步：选择裁剪策略

根据场景选择合适的策略：

| 你的场景 | 推荐策略 | 原因 |
|---------|---------|------|
| 刚开始对话，信息不多 | `full` 全量上下文 | 信息少，无需裁剪 |
| 对话变长，需要保持设定 | `headTail` 首尾保留 | 头部保设定，尾部保连贯 |
- 快速迭代，前面已过时 | `slidingWindow` 滑动窗口 | 只看最近消息 |
| 一个阶段完成进入下一个 | `manualCut` 手动截断 | 归档已完成内容 |
| 按时间管理的工作 | `expireTime` 过期时间 | 只看时间窗口内 |
| 信息密集但冗余多 | `fieldCut` 字段截取 | 只保留关键字段 |

## 第五步：开始对话

配置好策略后，正常与模型对话即可。TCK 会在后台自动处理上下文裁剪。

你可以在任何时刻切换策略，切换后立即生效于下一次请求。
